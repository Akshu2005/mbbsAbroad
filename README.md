README - Study MBBS Abroad Landing Page

Project Overview

This project is a responsive landing page for "Study MBBS Abroad," featuring country listings, program details, and a lead generation form. The page is designed using HTML, Tailwind CSS, and JavaScript, with optional PHP for backend form submission.

Features

Hero section with a call-to-action (CTA) button.

"Why Study MBBS Abroad" section highlighting key benefits.

Top countries section showcasing MBBS destinations.

Admission process and eligibility steps.

Lead generation form for collecting user details.

Form validation using JavaScript.

SEO optimization and integration with Google Analytics and Facebook Pixel.

Setup Instructions

Clone the Repository:

git clone git remote add origin https://github.com/Akshu2005/mbbsAbroad.git

Open the index.html file in a browser to preview the page.

For Form Handling (Optional):

Set up a PHP backend for handling form submissions.

Modify the form action attribute to point to the backend script.

Deployment:

Deploy on Netlify, Vercel, or any static hosting service.

Ensure Google Analytics and Facebook Pixel IDs are configured.

Technologies Used

Frontend: HTML, Tailwind CSS, JavaScript

Analytics: Google Analytics, Facebook Pixel
